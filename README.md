# A2Z Plant Nutrient

This is a full-stack web application built with:
- **Backend:** FastAPI, Python
- **Database:** Supabase (PostgreSQL)
- **Media Storage:** Cloudinary
- **Frontend:** React (Next.js / CRA)

## Setup

1. Configure `.env` using `.env.example` in the `backend` folder.
2. The database schema needs to be applied to your Supabase project (see schema in documentation).
3. The server will auto-seed initial content if the tables are empty upon startup.
